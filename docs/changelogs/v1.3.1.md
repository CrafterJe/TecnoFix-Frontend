# v1.3.1

### Corregido

- **Publicaciones — abrir la imagen descargada en Windows**: al guardar el PNG,
  el toast "Archivo guardado" ofrecía una acción **"Abrir"** que llamaba
  `openPath()` e intentaba abrir la imagen con su app por defecto; en Tauri esto
  fallaba en el layer de permisos (`open_path` está validado contra scope) y
  mostraba el error _"No se pudo abrir el archivo"_.
  - Ahora la acción es **"Ver en carpeta"** y usa `revealItemInDir()`, que abre el
    Explorador de Windows con el archivo seleccionado. Funciona para cualquier
    tipo de archivo y no depende de la app por defecto ni del scope de
    `open_path`.

### Detalles técnicos

- `src/lib/download.ts`: la acción del toast de `saveBlob()` cambió de
  `openPath` → `revealItemInDir`.
- `src-tauri/capabilities/default.json`: se añadió el permiso
  `opener:allow-reveal-item-in-dir`.

> **Nota de build**: por ser un cambio de permisos de Tauri, requiere recompilar
> el lado Rust (`npm run tauri dev` / build de Windows) para que surta efecto.
