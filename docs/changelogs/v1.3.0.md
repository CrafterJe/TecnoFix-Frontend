# v1.3.0

### Agregado

- **Módulo "Crear publicación"** (mini-Canva de marca): nueva sección en el
  sidebar disponible para **todos los roles** que genera publicaciones gráficas
  de Facebook / Instagram (retrato 1080 × 1350) con la identidad visual de
  TecnoFix.
  - 4 categorías con formulario adaptativo: **Dato curioso**, **Promoción /
    Oferta**, **Servicios** y **Tip / Consejo**.
  - **Vista previa en vivo** generada localmente en el navegador (sin red),
    mediante un `<iframe srcDoc>` escalado del HTML real del diseño.
  - 6 **fondos** (degradado morado/azul, morado, cian, crema, blanco); el logo
    se elige automáticamente (blanco en fondos oscuros, color en claros) por
    luminancia.
  - **Descarga del PNG** en alta calidad (2160 × 2700, escala 2x): en
    Tauri/Windows abre el diálogo nativo "Guardar como…" con toast "Abrir"; en
    web descarga directa.
- **`src/lib/download.ts`**: utilidad `saveBlob()` reutilizable que extrae el
  patrón de guardado (Tauri save dialog / `<a download>`) antes embebido en
  `PdfPreviewDialog`.
- **Documentación**: [`docs/publicaciones/doc-feat-crear-publicacion.md`](../publicaciones/doc-feat-crear-publicacion.md)
  (módulo front) y [`docs/backend-docs/publicaciones-exportar-png.md`](../backend-docs/publicaciones-exportar-png.md)
  (spec del endpoint del backend).

### Detalles técnicos

- La identidad visual y la generación del HTML se portaron de Node a TypeScript
  como lógica pura del front (`lib/brand.ts`, `lib/templates.ts`). Los logos se
  importan con Vite `?raw` y se incrustan como data URI base64 (en Node se leían
  con `readFileSync`).
- El mismo `renderDesign()` alimenta la vista previa del front y sirve de
  referencia para el render del backend, garantizando que el PNG sea idéntico a
  la vista previa.

### Backend dependency

- Requiere `POST /api/v1/publicaciones/exportar-png/` que reciba el objeto
  diseño y devuelva el PNG renderizado con **Playwright para Python** (Chromium
  headless, escala 2x). Spec completa en
  [`docs/backend-docs/publicaciones-exportar-png.md`](../backend-docs/publicaciones-exportar-png.md).
